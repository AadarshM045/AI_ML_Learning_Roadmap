# 🎓 EduManage – School Management System

A school management system for registering students and teachers, recording grades and viewing performance analytics. It comes in two versions that share the same data file:

- **Console app** (`main.py`): a menu-driven command-line program.
- **Web app** (`app.py`): a multi-page Streamlit interface built on top of the console app.

## ✨ Features

- 📊 **Dashboard**: total students and teachers, class average, pass rate, grade distribution, subject averages, top performers and recent registrations
- 🎓 **Students**: searchable directory, registration form, profile page, edit and delete, CSV export
- 👩‍🏫 **Teachers**: directory, registration (with optional department), profile, edit and delete, CSV export
- 📝 **Grades**: add or update marks per subject, remove marks, full gradebook view
- 📈 **Analytics**: leaderboard, per-subject statistics, mark distribution and a "needs attention" list for students below the pass mark
- 💾 **Data & Backup**: download a JSON backup, export CSVs, restore from a backup file
- ✅ **Validation**: valid email format, duplicate roll number / employee ID / email checks, marks limited to 0–100, sensible age ranges
- 🛡️ **Safe saving**: data is written atomically so a crash can't corrupt `School_data.json`

## 🚀 Getting Started

### 1. Requirements
- Python 3.9 or newer
- Streamlit 1.50 or newer (installed via `requirements.txt`)

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

On Ubuntu 23.04 and newer, if you are not using a virtual environment:

```bash
pip install -r requirements.txt --break-system-packages
```

### 3. Run the web app

```bash
streamlit run app.py
```

It opens at <http://localhost:8501>. If `streamlit` isn't found, use `python3 -m streamlit run app.py`.

> ⚠️ Run the web app with `streamlit run app.py`, not `python app.py` or the editor's play button.

### 4. Or run the console version

```bash
python3 main.py
```

## 🗂️ Data Format

Everything is stored in `School_data.json`, which is shared by both versions:

```json
{
    "Students": [
        {
            "name": "Aarav Sharma",
            "age": 15,
            "email": "aarav@example.com",
            "roll_no": "R-001",
            "grades": { "Mathematics": 88.5, "Physics": 72.0 },
            "registered_on": "2026-10-25"
        }
    ],
    "Teacher": [
        {
            "name": "Sunita Koirala",
            "age": 30,
            "email": "sunita@school.edu",
            "emp_id": "EMP-1",
            "department": "Science",
            "registered_on": "2026-10-25"
        }
    ]
}
```

`registered_on` and `department` are optional fields added by the web app. Records without them (for example, ones created in the console version) work fine.

## 🧯 Troubleshooting

| Problem | Fix |
|---------|-----|
| `Could not open requirements file` | You're in the wrong folder. `cd` into the project folder first (quote the path if it contains spaces). |
| `streamlit: command not found` | Use `python3 -m streamlit run app.py`, or add `~/.local/bin` to your `PATH`. |
| Yellow squiggles under imports in VS Code | VS Code is using a different Python interpreter. Use **Python: Select Interpreter** and pick the one the packages were installed into. |
| Data seems missing | Make sure `School_data.json` is in the same folder as `app.py`. |
